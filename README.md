# Product Roadmap

## **Azure UE MCP Plugin Roadmap**

### **Q1 Milestones**:
1. **Interactive Setup Window**:
   - Develop and integrate a user-friendly setup window into Unreal Engine.
   - Guide users through API key setup, Azure resource selection, and connection.
   - Include validation layers for user inputs.

2. **Neo Library Functionality Parity**:
   - Incorporate key Neo library features:
     - Endpoint management.
     - Real-time monitoring of Azure resources.
     - Asset synchronization workflows.

3. **Debugging and Logs**:
   - Build a real-time log viewer into Unreal Engine.
   - Display the success/failure of API calls and monitor Azure pipeline processes.

### **Q2 Milestones**:
1. **Testing and Validation**:
   - Create automated and manual tests for the plugin.
   - Test setup window functionality and API robustness (edge cases, failures).
   - Integrate tests into the Unreal Engine Automation Framework.

2. **Iterative Feature Improvements**:
   - Collect stakeholder feedback.
   - Address usability issues and implement enhancements.

### **Q3 Milestones**:
1. **Enhanced Documentation**:
   - Develop thorough user guides detailing plugin setup and usage.
   - Add real-world examples and success stories.
   - Include troubleshooting instructions for common issues.

2. **Community Contribution Guidelines**:
   - Outline how users can contribute to the project.
   - Clarify testing, feature requests, and pull request processes.
